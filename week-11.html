Week 11 · November 8, 2026

Works for Anyone with the Link

Key Learning Moments

This week we learned how to take what we built off our own laptop and put it online so anyone can use it. The professor's point was that it isn't done until someone else can open it. "It works on my machine" doesn't count. He explained that GitHub stores your code but a host actually runs it, and once they're connected, every time you push a change it redeploys on its own. Then he went through where to host depending on what you built: Vercel if it's JavaScript with a UI, Streamlit Cloud if it's a Python app, Render if it's a backend that has to stay running, and the publish button if you built it in something like Lovable.

The part that stuck with me was the mistakes. One example was a student whose API key was sitting in the browser code where anyone could see it. Another lost all their data because the free host wiped their files on redeploy. He said millions of keys get leaked on GitHub every year, and if you ever push one, treat it as stolen and revoke it, because deleting the commit doesn't remove it from the history. He also said to set a spending cap on the model before you share the link with anyone.

Personal Connections

This journal is on GitHub Pages, which he used as an example of a host that only serves files and can't run any code. That made sense to me, since my site is just plain pages and never needed to run anything. The key stuff also connected to my MVP plan from last week. I had already put the API keys inside the workflow tool instead of in any prompt, and set a spending cap as the very first task.

Challenges and Growth

The hard part for me is that my MVP doesn't really have a link. It's a phone call that goes out every morning. So "live" for me means the workflow keeps running on its own even when my laptop is closed, not a page someone opens. If I run it on my own laptop, the 7:30 call just doesn't happen the day my laptop is asleep. And for the judges, I need to figure out what the link even is, maybe a way for them to get a call themselves. He said to deploy in Week 12, not Week 15, so this is the next thing I need to solve.
