The Right Tool for the Job

My name is Rehan Dahiya. I am a sophomore at Penn State University Park studying Artificial Intelligence, and I am also the developer of Syntra AI, an educational AI platform. Because I already spend a lot of my time working with AI, I came into this class having used these tools for more than just asking questions or getting assignments done. Still, knowing how to use AI and knowing how to use it well are not always the same thing.

One idea from this week that stayed with me was that there probably should not be one AI tool that we rely on for everything. Different tools are good at different things. Sometimes one is better at writing, another is better for coding, and another might be more useful when you are trying to test something. It sounds simple when you say it like that, but I think it changes the way you approach AI. Instead of opening the same tool every time and expecting it to do everything, you first think about what the actual job is.

For this reflection journal, I chose GitHub Pages. I could have used something simpler, but GitHub made more sense to me because it gives me more control over the website and how I organize it as the semester goes on. It also feels closer to the kind of work I already do, so I would rather build something there than make a separate page somewhere just because it is easier.

I used ChatGPT while brainstorming how I wanted to approach the assignment. At first, it recommended Google Sites because it would be easy to set up and maintain. That suggestion was reasonable, but I did not end up following it. I thought about what I actually wanted the journal to look like over the semester and chose GitHub Pages instead. That was probably the clearest example this week of not treating an AI answer as the final answer just because it sounded practical.

After the website was set up, I used Claude Code for a different reason. I used it to stress test the site and check whether it was actually public, whether anything was broken, and whether another person could access it without special permissions. I did not want to look at the website from my own account, see that it worked for me, and assume that meant it worked for everyone.

I think that is what I am taking away from the first week. AI becomes more useful when I stop thinking about which tool is the best and start thinking about which tool makes sense for the thing sitting in front of me. And even then, I still have to look at what it gives me and decide for myself whether it actually works.
